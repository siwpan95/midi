关键类 & 算法（来自 pro1 原型，延续至 pro2）

InstrumentTrack

封装单声部 MIDI + 音频，通过 pretty_midi 合成，支持 program 编号（0=钢琴, 33=电贝斯, 40=小提琴…）

MusicMixer

多轨混音核心，立体声缓冲区累加，支持声相定位（0~1）、音量调节、防削波归一化，导出 WAV。

DynamicOrchestrator

动态声部管理器，支持最多 24 轨，带静音组（mute_group）、独奏层（solo_layer），实时增删声部。

IntelligentOrchestrator

根据情绪（happy/sad/epic/calm/tense）与复杂度（1-5）自动选择乐器组合，立体声场对称分布。

AutomaticArranger

按小节号安排编排事件（add/fade_in/fade_out/volume_change），支持回调函数实时更新 UI。

OptimizedRenderer (pro2)

2048 帧缓冲区 + 声相查找表，使用 numpy 向量化操作避免 Python 循环，float32 低内存渲染。

关键洞察 & 注意事项

⚠️

pro1 中的 mayvbe/ 目录 (pro2)

pro2/mayvbe/ 包含 17 个备选脚本（1.py~17.py），是功能探索的"草稿区"，未整合进主流水线，可作为功能扩展备用参考。

🔧

pro3 已知缺失文件

fix.txt 显示需要重新安装 numpy/pygame/pretty_midi/soundfile；SamplerTool.bat 文件大小为 0，未实现；Install.ps1 在结构图中标注但实际未见。

🎯

依赖重量级差异

pro1/2 依赖 numpy + scipy + librosa + pretty_midi 重量级 Python 栈；pro3 通过 .bat 调用轻量 Python 脚本，核心不依赖完整 scipy 栈，降低部署门槛。

🎵

SoundFont 是核心依赖

三版本均依赖 FluidR3_GM.sf2（约 140MB），需手动下载放入 soundfonts/ 目录。pro3 还支持 Libs/SoundFonts/default.sf2 自定义路径，pro3 提供 PrepareOfflinePackages.bat 辅助。

使用建议

🚀 按场景选择版本

  1. 学习 / 二次开发算法 → 使用 pro1：14个文件各自独立，类结构清晰，适合学习 MIDI 生成与混音原理。
  2. 需要 GUI 可视化编辑 → 使用 pro2/multi_track_music/3_daw_gui.py：带波形显示的完整 DAW 界面，快捷键完善。
  3. 非编程人员 / 批量生产 → 使用 pro3/MusicStudio：双击 .bat 全菜单驱动，支持离线安装，无需了解 Python。
  4. Docker 部署 / 服务化 → 使用 pro2/dockerfile.txt：基于 python:3.9-slim + fluidsynth 的完整镜像方案。
  5. 整合到现有项目 → 优先参考 pro2/config.yaml 的系统配置结构与 pro1/exa/1.py（ProjectPackage 数据类）作为项目存储方案。
